## 2. 先に再生リストを作る

YouTube Studio →「コンテンツ」→「再生リスト」→「新しい再生リスト」

- 名前：`AIのはじめかた 全10回【初心者・研修向け】`
- 説明：`ナビ犬のたぬきといっしょに、生成AI（Claude）のはじめかたから仕事での活用までを、1回10分・全10回で学ぶシリーズです。`
- 公開設定：公開

作ったら、再生リストの URL をコピーして、説明文の「（ここに再生リストのURL）」と置きかえます。

## 3. 本編をアップロードする

「作成」→「動画をアップロード」→ 本編の MP4 を選ぶ

**詳細**
- タイトル・説明文：`第01回.txt` からコピーして貼りつける（チャプターも説明文に入っています）
- サムネイル：`thumb_01.jpg`
- 再生リスト：「AIのはじめかた 全10回」にチェック
- 視聴者：「いいえ、子ども向けではありません」（Claude の利用は18歳以上が条件のため）
- 「すべて表示」をひらいて、次を設定します。
  - 改変または合成されたコンテンツ：**「はい」をおすすめ**（実写の犬の写真の口を加工して話させているため）
  - タグ：`AI, 生成AI, Claude, Claude Code, AI 初心者, AI 使い方, AI 研修, プロンプト, ChatGPT 比較`
  - 動画の言語・字幕の言語：日本語
  - カテゴリ：教育
  - コメント：オン

**動画の要素**
- 字幕：「字幕を追加」→「ファイルをアップロード」→「タイミングあり」→ `第01回_AIってなに.srt`
- 終了画面：「追加」→「1本の動画、登録」を選ぶ
  - 動画の最後の **9:39〜9:59（20秒間）** に表示します
  - 「動画」の枠は、画面左の点線の四角（「次の動画」）に重ねて、「最新のアップロード」を選ぶ
  - 「登録」の丸は、画面中央の点線の丸（「チャンネル登録」）に重ねる
- カード：第1回では設定しなくてOK。第2回を公開したら、第1回の 8:46（まとめ）に「第2回」へのカードを追加します

**公開設定**
- 「スケジュールを設定」で予約投稿にする
- おすすめは **火曜か金曜の 19:00〜20:00**（仕事や学校が終わって見る人が多い時間帯）
- 以降も同じ曜日・時刻に公開すると、見る人が習慣にしやすくなります

## 4. 公開されたらすぐやること

**固定コメント**：自分でコメントを書いて、「固定」します。

```
見てくれてありがとうございます！🐾
「AIのはじめかた」は全10回のシリーズです。次回は「Claudeを使いはじめよう」。
わからなかったところや、聞いてみたいことがあれば、コメントで教えてくださいね。
（ナビ犬 たぬき）
```

**ショート動画**：本編の公開から 1〜2日後に、1本ずつ公開します。

| | ショート① | ショート② |
|---|---|---|
| ファイル | `short_第01回_AIの苦手なこと.mp4` | `short_第01回_Claudeをおすすめする理由.mp4` |
| タイトル | `AIを使う前に知っておきたい4つのこと #AI #生成AI #shorts` | `どの生成AIを使えばいい？はじめの一つはこれ #Claude #AI #shorts` |
| 説明 | `本編「第1回 AIってなに？どれを使えばいい？」で、くわしく解説しています。` ＋ 末尾に `音声：VOICEVOX:ずんだもん` | 同じ |
| 関連動画 | 第1回の本編を選ぶ | 第1回の本編を選ぶ |

関連動画を設定すると、ショートの画面から本編へ1タップで移動できます。ショートを見て興味を持った人を、本編に連れてくる入口になります。

**コメントへの返信**：公開から 48時間は、コメントにできるだけ早く返信しましょう。

**広める**
- 社内研修で使う場合：社内ポータルやチャットに、再生リストの URL を共有する
- 学校・就職支援の場で使う場合：先生や担当者に URL を紹介する

## 5. 1週間後に見ること（YouTube Studio →「アナリティクス」）

- **インプレッションのクリック率**：4％より低ければ、サムネイルの文言を見直す
- **平均視聴率／視聴者維持率**：大きく下がっている場面があれば、次回以降の台本で短くする
- **登録者の増加**：本編とショート、どちらから多く増えたかを確認する
